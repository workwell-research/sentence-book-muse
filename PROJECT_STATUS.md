## Current scope
**2026-10-29 — generation is live locally.** `/api/generate` now calls Meta Model API (`muse-spark-1.3`, OpenAI-compatible Chat Completions with `response_format: json_schema` built from the shared Zod contract, `reasoning_effort: low`, 90s timeout, 32KB request cap). The server validates the request, calls the model once, re-parses the output with `validateLessonDraft`, and returns `{contract, draft, model, usage}` or a coded error (503 not configured, 400/413 request, 429 with Retry-After, 502 upstream/invalid output, 504 timeout). Nothing is stored server-side. On `/setup`, 「教材を作る」 is enabled when an interest or topic exists, keeps one draft ID per distinct content for retries, re-validates the response in the browser, shows a read-only preview (sentences, questions with sample answers, review expressions, filing proposal with reason/tags) and keeps the page under `sentence-book-muse:pending-drafts:v1` (newest first, de-duplicated by draft_id, max 50, unreadable data never overwritten). The shelf's 「仕分けを待つページ」 count reads that key. Filing approval, binders, practising a generated page and deployment are still not implemented. See the 2026-10-29 verification section.

The owner's latest [Work desktop handoff](docs/desktop-study-desk.md) is implemented locally at `/`: Pure White / Natural / Walnut desk materials, six horizontal pen radios, optional timer, open index book, read-only model card and one native editor on the current A5 line. The notebook keeps the adopted physical A5 composition and the Japanese phrase-gloss 1mm lift. The previous standalone typography demo remains at `/handwriting`; saved interest/topic setup remains at `/setup`.

The synthetic eight-sentence Copy sample starts at zero. Draft handwriting now appears as letters are typed, at the native input coordinates, without a following pen graphic. Matching input is checked and saved on Enter without replaying the body, then the next line receives focus immediately. During editing, the paper scrolls within the remaining viewport below the model, following the caret vertically and horizontally so both stay visible. Associated annotations continue without an automatic pen while editing. The eighth correct Enter completes Copy. Five English-only paper index tabs touch the model card; all five have equal widths, Copy is light gray, and stages2–5 are paler gray and disabled. Sequence/status badges, the current-line jump and all Next buttons are removed. Enter is the sole check/save/advance operation; legacy confirmed records open the next editable line in memory without a load-time write. Option+R / Alt+R reads the current model with an on-button hint and playback/error feedback. Actual local drafts, confirmations, review marks, personal writing and display settings persist under two new keys. This is one sample record, not a generated lesson or multi-lesson history. The old app and its real learning data remain unchanged; only its shared status records this work.

A5 is the finished note (148 × 210mm); A5/A4 are printer-sheet choices. A4 repeats each A5 page twice at 100%. Readability Italic remains the English default, with EMS Tech / Print / Pen and Klee One / Zen Kurenaido available. PDF uses independently rendered vectors and canonical confirmed text, excluding the desk, editor and unconfirmed drafts. Physical printing remains unverified.
