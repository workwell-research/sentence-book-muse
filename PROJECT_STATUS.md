## Current scope
The owner-authorized first increment of [Work’s adopted notebook design](docs/studygram-notebook-implementation-spec-2026-10-27.md) is implemented at `/`: shared physical A5 composition, measured sentence/gloss/footnote placement, memo shown/blank controls and matching vector PDF. Blank memos preserve reserved rows, body wrapping, other study blocks, personal writing/checks and page count. The common plan comes from the exact refill JSON; generated images remain appearance references.

The notebook standard is generic A5 portrait (148 × 210 mm). A5/A4 are separate printer-sheet choices; A4 repeats each finished A5 page twice at 100%. Six accents share graphite body ink with blue default. Mobile fit/scrollable larger viewing changes scale only. Final handwriting assets remain provisional and are not approved by layout acceptance or the scoped finish review.

The actual sample is synthetic, not Meta-generated content or a completed lesson. Personal writing, review checks and view/print choices are session-only. Existing saved interests and topic notes remain available at `/setup` and were not migrated. The separate old app is unchanged except its shared handoff record. See [the feature note](docs/handwriting-prototype.md) for architecture, provenance and pending learning integration. React/Web remains the active platform; Flutter was exploratory.

## Implemented
- `StudyContent` with stable IDs and validated Unicode-code-point gloss occurrence spans; `createA5Layout` measures actual English/Japanese advances into fixed A5 grids before view filtering. Long content uses continuation pages, with explicit errors for overlong indivisible metadata/entries rather than shrinking/clipping.
- Shared 148 × 210 mm refill: default left18/right12 mm, 31 body rules at 5.2 mm, 1.6-row title band, main column and right footnote rail. SVG and PDF independently render the same millimetre plan.
- Native memo shown/blank controls omit only gloss/footnote/correspondence ink. Vocabulary English/Japanese/checks, grammar, personal input, columns and reserved space remain. Sentence-only keeps body positions and remembers the temporarily disabled memo setting. Screen markers and print-marker override are separate.
- Six labeled accent radios with blue default and common graphite body/personal ink. Playback, pause/resume, speed, replay/finish, reduced motion, following pens and editable personal stroke identities remain. Input/checks/settings are session-only and disclosed.
- Fixed paper view with fit or 740 px scrollable readable size on narrow screens, without responsive text reflow. Memo accessible text is omitted when hidden. Keyboard/native controls remain available.
- Independent vector PDF: generic A5 finished page/TrimBox or landscape A4 at x0/149 mm, scale1, with 1 mm cut strip; current sample and each continuation page repeat twice. Left/right binding and 12/18/24 mm choices affect the common plan. White print paper, optional markers, PrintScaling=None and explicit 100%/already-imposed instructions.
- Third-party Cutlings Singularis-derived stroke assets and new static Japanese M PLUS 1p TTF retain OFL/provenance. Full TTF embedding preserves kana outlines; font advance metrics are generated from the bundled original. Neither font is first-party hackathon artwork. English PDF lettering remains unsearchable vector paths.
- First-run interest selection: multiple choices, custom additions, explicit save, skip, later edit/clear and non-destructive failure handling. No binder is created by selecting interests.
- Interest-aware generation request validation and a pure Muse message builder. Casual notes become source material for useful communication situations; actual model output is not yet tested.
- An empty shelf with no preset themes, plus a topic/language/level note. New binders will be proposed from pages and require learner approval.
- New sentence_book_page_v1 contract, shared Zod validation and JSON Schema export in shared/lesson-schema.ts; see docs/generation-contract.md. This is not a recovered legacy v2 schema.
- Separate localStorage keys for interests and the existing topic note, with explicit save, restore and non-destructive error handling. Profile changes preserve note data.
- Vite/React/TypeScript configuration; Pages Functions health route and unavailable generation route.
