## 表示設定

設定はノート外の操作エリアにまとめる。印刷面には操作UIを載せない。

| 項目 | 表示する選択肢 | 動作 |
| --- | --- | --- |
| ノートに載せる内容 | センテンスのみ／単語・イディオムも載せる | 前者は英文、ヘッダー、フッターと罫線。後者は供給された語彙欄や学習補助欄も使う |
| 学習メモ | 表示する／空欄にする | 語句直下の意味と右カラムの脚注を表示するか、同じ場所を空けるか |
| マーカー | 表示する／表示しない | 背面のマーカーだけを切り替える。文字、枠、余白は保持 |
| ノートの色 | ブルーを基準に既存の6色 | 本文は共通の濃いグラファイト。色は主にマーカーと小見出しへ使う |
| 印刷の色 | 通常のノート／赤シート用 | 後述の英語の対象範囲だけを印刷色へ変更 |
| 印刷用紙 | A5／A4横2面 | 同じ原寸A5を配置。用紙選択でノートの書式を変えない |

初回設定は「単語・イディオムも載せる」「メモを表示する」「マーカーあり」「ブルー」「通常印刷」「A5」とする。これは採用見本を再現するための実装初期値。既に保存された選択があれば引き継ぐ。

センテンスのみを選んだ場合は学習メモの切替を無効にし、「学習メモは単語・イディオム付きで使えます」と操作側に添える。直前のメモ設定は保持し、単語付きへ戻すと復元する。マーカーはどちらの内容形式でも独立して使える。

構文欄と自作文欄は、当該ページに内容がある場合だけ載せる。単語表示を選んだことを理由に、新しい解説や自作文を自動生成しない。現段階で細かい欄ごとの切替を増やす必要はない。

## メモを空欄にする動作

「学習メモ」が制御するのは、本文の難しい表現に添える短い意味と、右カラムの言い換えやニュアンス。単語欄の英語と和訳、構文の英文とラベル、自作文の英文と直下和訳は、それぞれの内容ブロックに属し、この切替では消さない。

| 部分 | メモを表示する | メモを空欄にする |
| --- | --- | --- |
| 本文英文と行間 | 既定の行割りで描く | 同じ位置、折返し、ページに描く |
| マーカー直下 | 供給された難語の短い意味 | 意味の文字だけを省き、書込用の罫線を残す |
| 右カラム | 供給された脚注と対応印 | 脚注本文、矢印、注番号を省く。縦の区切り線と幅、高さを残す |
| 下部の単語枠など | 選んだ内容を描く | 位置、枠、内容、チェック状態を保持 |
| ヘッダーとフッター | 共通の書式 | 共通の書式 |

空欄へ「ここにメモ」などのプレースホルダー、点線の文字、見えない答えを印刷しない。画面の説明は操作エリアに置き、ノートの読み上げ説明も実際の表示状態に合わせる。

表示用データを変更せず、組版済みレイアウトからメモのインクだけを省く。メモを表示する場合の文字幅と高さを先に測り、空欄でも同じ領域を予約する。長い脚注がある場合も、切替だけで後続欄やページ数を動かさない。元々メモがないページでも、単語付きでは右の書込カラムを確保する。

元の解説、本人の追記、復習チェック、書取り途中の状態は削除しない。この切替は紙に自分で書き込む使い方を支えるもので、ペン入力やメモ編集機能の追加は別の要件とする。既存の本人の追記を自動解説で上書きしない。

「空欄」は、センテンスのみ見本から推測して紙を作り直す方式ではない。単語付き見本の意味メモと右脚注の文字だけを除いた状態が正しい。独立した空欄版の生成画像は現時点ではなく、この表を実装基準とする。

## 共通リフィルの座標

単位はmm。左上を原点とし、横方向をx、下方向をyとする。全表示とPDFで、同じA5リフィルを使う。

| 項目 | 値 |
| --- | --- |
| 完成ノート | A5縦 148 × 210 |
| 標準の綴じ代と外側余白 | 左18、右12 |
| 本文罫線の横範囲 | x18〜136 |
| 本文の最初と最後の罫線 | y39.2〜195.2 |
| 本文罫線の間隔と本数 | 5.2、31本 |
| 本文罫線の線幅と色 | 0.10、#D7E0E7 |
| タイトル欄の上線と下線 | y24.64、y32.96 |
| 専用タイトル欄の高さ | 8.32、本文ピッチの1.6倍。内部の通常罫線は0本 |
| フッター区切り | y201 |
| タイトル上下とフッターの線 | x0〜136、線幅0.35、色#D7E0E7 |
| 英語分類の基線 | x136、y11、右揃え |
| 日付とページ番号の基線 | x136、y17、右揃え |
| タイトルの基線 | x18、y31、左揃え |
| フッター文字の基線 | x136、y206、右揃え |

ヘッダーとフッターの区切りは、本文線より太く、色の濃さは本文線と同じ。本文の左余白に合わせて短くせず、紙の左端まで引く。専用タイトル欄は本文罫線の2行を流用しない。

原本の紙色は画面用#FFFEFB。印刷では紙そのものの白を使い、紙色や質感を塗り潰さない。全色、メモ表示と空欄、マーカー有無、印刷色、内容形式で寸法、線位置、倍率を共通にする。

現行の追加綴じ代設定を扱う場合は、左右12／18／24mmの明示的な紙設定として、画面とPDFの両方へ同じ座標計算を適用する。本文だけの形式やメモ空欄を選んだことを理由に余白を変えない。まず左18mmの標準原本で全形式を揃える。

### カラムと文字の初期値

本文はx18〜104、右カラムの縦線はx106、脚注本文はx108〜136を組版の初期値とする。カラムは英文と脚注がある本文区間に使い、単語枠の前の空行へ縦線を伸ばさない。メモ空欄でも同じカラム、センテンスのみでも同じ英文幅と行割りを使う。

メインタイトル16pt、本文英文10.5pt、右脚注8.5ptを文字サイズの初期目安とする。難語の意味は本文より小さくし、読める細さを保つ。タイトル以外は前版より約20%細いペンの印象とし、文字色を薄くして代用しない。最終のサイズと線幅は実字形で測り、採用見本の密度と印刷時の読みやすさを両立させる。長文を収めるために縮小しない。

本文色は#383A3D、小見出しと構造用の青は#47627A、ブルーのマーカーは#D5E7F2を初期値にする。既存の6色は維持し、本文をページ全体のテーマ色で染めない。マーカーの透明度を文字にかけず、淡色を文字の背面へ1回だけ描く。

## ヘッダーとフッターの内容

分類は英語で、右上の日付の上に置く。実際に本人が確認した分類先と安定IDを使い、固定テーマ数や新しい分類を再導入しない。分類済みで英語表示名だけが未設定の場合は、元分類を保持したまま英語表示名を確認できる経路を用意する。未分類のページだけ `Unfiled` とする。

日付は学習ページに紐づく日付を用い、書式切替や再印刷で今日の日付へ上書きしない。ページ番号は実際のリフィルの順番に対応させる。日付未確定の下書きでは完成日を捏造しない。

長い分類名は共有された上部メタデータ領域内で折り返し、長いタイトルは専用帯内の読みやすい折返しを実測する。入らない場合は、本文位置を押し下げず、表示用短縮名と全文確認の仕組みなど明示的な処理を使う。元の文字列を保存し、無断で切り捨てない。

フッターは小さく右揃え。見本の `visual study` は制作見本の識別文であり、実教材には製品名と実際のページ情報を使う。文字の大きさと位置、上の太い淡色線は見本に揃える。

## 英文と学習補助欄の組版

### 書取りの行送り

英文の基線は罫線と同じy座標に置く。a／e／nの足元は線に乗せ、g／j／p／q／yの下に伸びる部分は線の下へ出す。単語の外接枠の下端を一律に揃えず、字形の基線、x-height、上昇部、下降部、送り幅から配置する。

短い1文は1行で書き、その次の罫線1行を空ける。次の文の基線は2ピッチ、10.4mm先。8文がそれぞれ1行に収まる見本は行0、2、4、6、8、10、12、14に置く。本文最初の基線は39.2mm、最後は112.0mmになる。

長い文は実際の字幅で折り返し、通常は次の罫線へ続ける。文の最後で1行空ける。途中の行に難語の直下メモが必要なときだけ、その下に注釈用の罫線1行を予約してから英文を続ける。この予約はメモ空欄でも維持する。英文に1.5行などの端数送りを使わない。

### マーカー直下の意味

意味が難しいと指定された語句にだけ、短い意味を添える。すべてのマーカーへ意味を付けたり、各文の全文和訳を追加したりしない。語句のx位置に揃え、その直下の予約行に小さい文字で置く。

見本は `made time for → 〜のために時間をつくった` と `settle in → 落ち着く`。これを難語の固定リストにせず、教材で供給された語句情報を使う。長い意味や複数の意味がぶつかる場合は行を追加して組版し、本文や他のメモへ重ねない。

### 右カラムの脚注

右カラムは言い換え、使い分け、ニュアンスを少数載せる。本文全体の日本語訳を流し込む欄にしない。該当する文の横に揃え、必要なら小さな矢印や注番号を使う。

見本は `slow down ≈ take things slowly`、`Instead of checking my phone → rather than checking my phone`、`It did not have to be anything special. → It could be something simple.`。最後は厳密な同義文でなく、意味を補う説明として扱う。供給されていない脚注を空きスペース埋めのために生成しない。

脚注は右カラム内で折り返す。前の脚注と重なる場合は後続注を下げて対応印を保持する。本文と脚注の両方の下端を測り、次の欄の開始位置を決める。

### 単語とイディオム

本文区間と単語枠の間は、丸1行の罫線を空ける。単語欄全体を1つの細い四角枠で囲み、各項目に空の復習チェックボックス、英語、短い和訳を置く。初期値は枠線0.25mm、チェック四角2.5mm。チェックは本人の復習の印で、自動正解や学習完了を意味しない。

単語の英語と和訳は「ノートに載せる内容」で選ぶ内容であり、「メモを空欄にする」でも保持する。赤シートでも和訳、枠、チェックは暗色で残す。

### 構文と自分の英文

ページに供給された構文欄は英文と対応括弧、短いラベルをまとめる。自分の英文の下に小さい和訳を付ける場合は、空行を入れず密接な対訳にする。和訳の文字高は英文の約68%、基線間隔は0.6罫線ピッチを初期値とする。この対訳だけは通常の整数行送りの例外。

見本の `Instead of rushing, I took a short walk.` と `急ぐ代わりに、少し散歩をした。` は架空例。実際の本人の自作文や既存追記を置き換えない。

### 長い内容とページ送り

単語、解説、脚注が増えても、紙を縦へ伸ばしたり、罫線を詰めたり、字を縮めたりしない。同じリフィルの次ページへ送る。英文とその直下の意味は原則として同じページに保持し、枠の見出しだけがページ末尾に孤立しないようにする。

1文が1枚の本文領域より長い場合は、行単位で続けて文IDと続きを保つ。分割したページに分類、タイトルとフッターを再描画する。生成メモだけでページを超える場合も、同じ原本へ対応元を明記して続ける。継続ページを含めた行割りを確定してから、メモ表示、空欄、マーカー有無を描き分ける。

## 画面とPDFの関係

紙の座標と内容の行割りを共通のレイアウト結果にまとめ、画面とPDFが別々に改行を決めない構造にする。PDFは独立したベクター描画を維持し、画面の幅、スクリーンショット、アニメーションの再生時刻へ依存させない。

画面の小さな端末では、印刷ページの内部寸法を崩さず、ズームや横スクロールで読めるようにする。操作側は縦に並べ、ラベル、フォーカス、キーボード操作、44px程度の押せる領域を確保する。別の読みやすいリフロー表示を設ける場合は印刷プレビューと区別する。

PDFは選択中の内容形式とメモ設定を使う。印刷マーカーの省略は独立して残し、未指定なら画面に従う。優先順は「内容形式を選ぶ → 共通の行割りを確定 → メモの文字を表示または省略 → マーカー設定 → 赤シート色」を守る。

A5用紙には148 × 210mmの1ページ。A4横297 × 210mmには同じA5を倍率1でx0とx149mmに2部配置し、x148とx149mmの1mm裁断帯を維持する。複数ページでは各リフィルをこの同じ規則で2部ずつ配置する。冊子の面付けや別々の日付の自動配置へ読み替えない。

PDFのPrintScalingはNoneとし、操作側で100%の実際のサイズを案内する。フォントや図形を埋め込んだベクターを使い、空欄にしたメモのインクをPDFへ出力しない。通常印刷と赤シート印刷で座標と改ページを変えない。

## 赤シート印刷

隠す基本対象は本人が選んだ英単語とイディオム。和訳を残す。本文だけでなく、単語欄、構文、自作文、脚注、タイトルに同じ答えが再登場する場合も、指定された活用形と範囲を揃えて処理する。右欄の英文を無条件に全部隠さない。

対象語の背面にマーカーを重ねず、黒い縁取りや暗色の二重筆跡も重ねない。他のマーカーは選択された設定に従う。画面の通常閲覧は読みやすい暗色のままとし、印刷プレビューには選択した出力を示す。

色は試刷りPDFのオレンジ、赤、ピンクの候補から実物で選ぶ。実プリンターと赤シートでの隠れ方は未確認なので、特定の色コードの効果を保証しない。通常印刷を使える状態を保ち、「まず1枚、色を試す」と試刷りへ案内する。

## データと書取りの状態

表示設定と学習内容を分ける。元のページ、文、語句、分類先、本人の追記、チェック、途中入力、完成履歴を保持する。メモの空欄化、色変更、印刷設定で、文のIDを採番し直したり、書取り済みの行を消したりしない。設定の再描画で練習や筆跡再生を先頭へ戻さない。

文、語句直下の意味、右脚注は安定IDで結ぶ。英語の対象位置は、元の文と一致する語句および開始と終了位置を検証する。同じ語句が複数あるとき、最初に見つかった文字列だけを色付けする実装を避ける。文字位置の単位はアダプターで明示し、Unicode文字とSVG字形の対応を揃える。

既存の生成契約や保存モデルを本仕様で置き換えず、その実データからノート用の表示モデルへ変換する。難語や脚注の情報が未供給なら空欄を使い、実装担当が架空の本文や意味を補って完成扱いにしない。保存済みの本文全訳があっても削除せず、このノートの右欄に自動投入しない。

英語の写経は本人の練習操作と結び付ける。筆跡アニメーションだけの完走や、表示設定を変えたことを学習完了として記録しない。デモ表示と本当の練習結果は区別する。

既存の字形は英数字中心の仮素材。日本語の意味や和訳は、ライセンスを確認した日本語フォントの埋込みなどで欠落なく描く。日本語の筆順素材がない場合、静的な読みやすい日本語文字を使い、対応していない筆順アニメーションを実装済みとしない。

## 受入条件

| ケース | 確認する結果 |
| --- | --- |
| 単語付きでメモ表示 | 採用見本の階層、短文1行おき、難語だけ直下の意味、右欄の少数脚注、単語枠とチェックが揃う |
| 単語付きでメモ空欄 | 意味と右脚注の文字と対応印だけが消え、カラム線、予約行、単語欄、本文基線、改行、ページ数が変わらない |
| センテンスのみ | 同じ紙、本文幅、基線と改行。右カラム線と学習補助ブロックを省き、通常の罫線を残す |
| マーカーOFF | 文字、意味、脚注、枠を保持し、マーカーだけを省く。メモ空欄とも組み合わせられる |
| 設定を戻す | メモとマーカーが再表示され、ID、本人の入力、チェック、学習進捗、再生位置を保持する |
| 同じ語句が複数回ある | 指定された出現位置だけが正しくマーカーや赤シートの対象になる |
| 長文と長いメモ | 重なり、切れ、フッター侵入、見出し孤立がない。縮小せず同じ紙へ続き、空欄切替で組版が動かない |
| 英字と日本語 | 通常字は罫線へ接し、下降字は下へ。日本語の意味、和訳、句読点が画面とPDFで欠けない |
| A5とA4 | PDF寸法が正しく、A4の2部は原寸で同じA5。マーカーやメモの切替で位置が動かない |
| 赤シート | 英語の指定対象と活用形を処理し、単語欄の和訳、枠とチェックを残す。対象の下にマーカーを重ねない |
| 狭幅とアクセシビリティ | 320pxと390px相当でも操作が読め、紙を拡大して読める。キーボード、読み上げ、Reduced motionを保つ |
| 実物印刷 | 100%印刷の寸法、線の淡さ、文字の読みやすさ、綴じ代、赤シートの隠れ方を実物で確認する |

機能担当は内容2種 × メモ2種 × 画面マーカー2種の組合せを確認する。センテンスのみではメモ設定は結果に影響しない。メモの切替はレイアウト結果の同一性を単体で確認し、実際に出力したPDFと画面でも照合する。通常の変更検証とビルドを行い、専用の別originと架空fixtureを使う。

## 実装の進め方

まず共通リフィルと文字の基線を、画面とA5 PDFに適用する。次に文と注釈の行割りを共通化し、メモ表示と空欄を追加する。最後に長い内容のページ送り、A4配置、赤シート用の範囲処理を組み合わせて確認する。

採用されたのはこの構成と見た目の方向、メモ表示と空欄の選択要件。最終の字形、長文組版、実物の印刷は実装後に確認する。本引き継ぎ時点で、これらの新機能が機能repoへ統合されたとは扱わない。
