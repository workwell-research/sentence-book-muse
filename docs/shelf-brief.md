# Shelf and topic note

Mode: Operate. The first useful action is saving what the learner wants to say. The shelf communicates where future pages will accumulate, without pretending generated lessons exist.

First viewport: wordmark, a short Japanese invitation, five muted binders beside a paper note on desktop. Mobile stacks the shelf and note, with a direct jump to the form.

States: empty shelf, empty or restored topic, unsaved changes, save success, failed storage, unreadable prior note and unavailable generation. Persistence failures never clear the input or overwrite unreadable data. No motion is required beyond optional smooth anchor navigation, disabled for reduced motion.
