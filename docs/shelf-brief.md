# Shelf and topic note

Mode: Operate. The first useful action is choosing a few interests, then optionally saving what the learner wants to say. The shelf communicates where future pages will accumulate, without pretending generated lessons exist.

First use: wordmark and an invitation beside interest checkboxes and custom input. Save or skip goes to the empty shelf and paper note. Returning use: an editable interest summary beside the note. Mobile stacks the two columns with a direct jump to the active task.

States: missing/saved/skipped interests, custom additions, editing and cancellation, interest storage failure, unreadable profile, empty shelf, empty or restored topic, unsaved changes, note save success/failure, unreadable prior note and unavailable generation. Persistence failures never clear the input or overwrite unreadable data. No motion is required beyond optional smooth anchor navigation, disabled for reduced motion.
