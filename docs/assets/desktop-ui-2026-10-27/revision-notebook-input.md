2026-10-27の本人の訂正：「ちなみにフラッシュカードはお手本で、書くのはノートだからね」。**本訂正を入力配置の最優先とする。** 以前のカード内入力の見本と契約は置換する。本人のDesktop UI Version 1.0は[原文](owner-spec.md)として保存し、カード内入力に関する箇所は今回の訂正を優先する。

| A5ノートの現在行 | 本文の罫線に沿う単一の入力欄。入力文字とカーソルを表示 |
| ノートの脇 | 確認ボタンとEnterの案内。紙の内容を覆わない画面用の操作 |

## 実装へ渡す入力契約

[notebook-input-interaction.json](notebook-input-interaction.json)を正本とする。ノートの現在行にネイティブな入力欄を1つ置き、カード側の編集欄は0個にする。紙の上に透明な背景で表示し、角丸の別フォームに見せない。入力位置は共通A5の現在文/現在行の計測から決め、固定の画面ピクセルや画像の文字位置から決めない。

ネイティブな選択、カーソル、キーボード、IME、貼付けを保持する。入力文字と確定後の筆跡は同じ組版の基線/幅/改行を使い、二重表示や別の場所への転送を起こさない。確定時には実際の入力結果を検証/保存してから同じ位置の筆跡へ反映し、演出の完了だけで学習済みにしない。次へ進む操作の扱いは既存の学習フローに合わせる。

長い文は、紙の行割りと継続ページの計画に従う。必要な入力行を語彙欄や構文欄に重ねない。現在行はスクロール/読める拡大で追えるようにし、入力欄のためにA5全体や文字を縮小しない。カードの外形は固定し、長いお手本は内部の折返し/読めるスクロールで扱う。Dictation等で手本を隠す場合も、カードを第2の入力欄にはしない。各学習段階の提供範囲は実装に従う。

横向きの6色ペン、小さめのインデックス、3テーマの文具/タイマー、タイマー任意表示は維持。テーマ/色/メモ/タイマー表示の変更で入力やIMEを作り直さない。カード、確認操作、カーソル、未確定の下書き表示はノートPDFに含めず、共通組版の確定済み内容を出力する。元の学習データ/ID/履歴を変更しない。
